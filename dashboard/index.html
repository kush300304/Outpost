            What the words mean
            
    
                
    HIT
    
                
    The edge answered from its memory, within the entry's time to live (ttl).
    
                
    MISS
    
                
    The edge had no copy and fetched the value from the origin (write-api → storage).
    
                
    REVALIDATED
    
                
    The edge asked the origin "is my copy still current?" with its ETag; the origin said yes
                    (304), so the value was not sent again.
    
                
    304
    
                
    Not Modified: the client already had this exact version (its If-None-Match matched the ETag), so no body was sent.
    
                
    STALE
    
                
    The origin is unreachable, so the edge served its older copy instead of failing, for at
                    most ttl + stale-if-error.
    
                
    QUEUED
    
                
    The origin is unreachable, so the edge saved the write in its local write-ahead log (202)
                    and delivers it, in order, once the origin is back.
    
                
    Circuit breaker
    
                
    CLOSED: the origin is healthy. OPEN: after 3 failures the edge stops calling it.
                    HALF_OPEN: after a pause, one probe tests whether it is back.
    
                
    ETag
    
                
    The identity of the write that produced a value ("version-writerId"), used to ask
                    "has this changed?".
    
                
    Writes per fsync
    
                
    Storage makes every write durable before acknowledging it; writes that arrive together share one
                    disk flush (group commit).
